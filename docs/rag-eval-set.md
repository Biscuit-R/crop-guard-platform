## 为什么要改写，而不能直接用

起草者的任务是「读图鉴 → 写症状描述」。这必然导致一个问题：

**我会不自觉地使用图鉴自己的词汇。** 比如语料 001 写着「纵卷叶片成圆筒状虫苞」「形成白色条斑」，我就容易写出「叶片卷成圆筒状虫苞并出现白色条斑」—— 而这个词串和语料高度重合，向量检索**几乎必然命中**。

真实场景不是这样。农户看到的是「稻叶子卷起来了，发白了」。**这个用词落差才是这个系统的真实难度。**

所以：**默认草稿偏简单。** 每条的「生成」列标了它的来源：

| 标记 | 含义 | 改写优先级 |
|---|---|---|
| **直译** | 基本照抄语料措辞 | **高** —— 这类几乎白送，不改成口语就是自证 |
| **口语** | 已刻意用农户口吻写 | 中 —— 看是否真的像农民说话 |
| **近缘** | 有明确混淆对象 | 中 —— 但**别改掉歧义**，歧义本身就是考点 |

## C · 使用方式

```
阶段 4 写完切分与检索后：
  1. 用本集跑 top-k 曲线 → 定 top-k
  2. 记录每条的 max(similarity) 分布
       → 30 条症状题的最高分聚类   → 定「高阈值」
       → 10 条无关题的最高分聚类   → 定「低阈值」
  3. 若两组分布重叠 → 阈值无法同时满足两条标准，回到 B 节的三条路重选
```

**关键**：阈值是**两组分布的分界**，不是拍出来的数字。**若两组分布重叠，说明当前 embedding 分辨不出「沾边的农业问题」和「真正的虫害问题」** —— 那才是要先解决的问题（换 embedding / 加混合检索 / 改切分），而不是硬调阈值。

## D · 关于「谁出题」

本集由 AI 起草，**不是因为 AI 出得好，是因为你手上没有真实用户提问记录**（未上线）。

**这件事本身就是面试素材**：被问「你怎么建评测集」时，可答 ——

> 「我的语料是 102 条结构化图鉴。我最初的评测集是 AI 按图鉴生成的，跑出来命中率很高 —— 后来我发现问题：**生成者用的是图鉴的词汇，所以检索必然命中**。真实农户说的是『稻叶子卷起来了发白』，不是『叶片纵卷成圆筒状虫苞』。所以我把它逐条改写成口语，并且专门保留了一批语料自己标注『与 X 相似』的近缘条目。**改成口语之后命中率掉了一截 —— 那才是真实数字。**」

这段话里有：发现偏差 → 定位原因 → 修正方法 → 量化对比。比「我建了评测集」强一个量级。
