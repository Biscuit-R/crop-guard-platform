## 6. 扩展性设计

### 添加新的高级功能

1. **创建后端 API**
```python
# backend/app/api/new_feature.py
router = APIRouter(prefix="/new-feature", tags=["新功能"])

@router.get("/endpoint")
async def new_endpoint():
    return {"message": "新功能"}
```

2. **注册路由**
```python
# backend/main.py
from app.api.new_feature import router as new_feature_router
app.include_router(new_feature_router, prefix="/api")
```

3. **创建前端页面**
```vue
<!-- frontend/src/views/NewFeaturePage.vue -->
<template>
  <div>新功能页面</div>
</template>
```

4. **添加路由**
```javascript
// frontend/src/router/index.js
{
  path: "/tools/new-feature",
  name: "新功能",
  component: () => import("../views/NewFeaturePage.vue"),
}
```

5. **更新侧边栏**
```javascript
// frontend/src/components/Sidebar.vue
const advancedMenuList = [
  // ... 现有菜单
  {
    name: "新功能",
    icon: NewIcon,
    path: "/tools/new-feature",
    badge: null,
  },
];
```

6. **更新高级功能首页**
```vue
<!-- frontend/src/views/AdvancedFeaturesPage.vue -->
<el-card class="feature-card" @click="navigateTo('/tools/new-feature')">
  <!-- 功能卡片内容 -->
</el-card>
```
